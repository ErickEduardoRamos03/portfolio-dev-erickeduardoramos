## Ejecutar localmente

1. Clona el repositorio:

   git clone https://github.com/ErickEduardoRamos03/portfolio-dev-erickeduardoramos.git

2. Entra en la carpeta del proyecto:

   cd portfolio-dev-erickeduardoramos

3. Instala dependencias:

   npm install

4. Inicia la aplicación en modo desarrollo:

   npm run dev

   o, si el proyecto usa Vue CLI:

   npm run serve

5. Abre tu navegador en la URL que indique la terminal (por ejemplo http://localhost:3000).

Si el proyecto está desplegado (GitHub Pages, Netlify, Vercel), puede que no requiera pasos locales.
